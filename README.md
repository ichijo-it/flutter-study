# flutter-study
## display_resource_image  
Flutterアプリケーション。画像やWidgetを表示するサンプルアプリ。  
詳細はこちらを参照。  
* [display_resource_image/README.md](display_resource_image/README.md)  
  
## server  
Dartを使用したHTTPサーバー。
ローカル環境で画像・JSONファイルを配信する。

#### 起動方法  
以下のコマンドを実行し、起動する。  
```dart  
dart run .\image_http_server.dart
```
